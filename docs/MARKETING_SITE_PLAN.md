# Studio Marketing Site Plan

Status: Planning document only

Repo: signal-interface/studio-marketing

## Purpose

Studio is the creative execution layer.

Studio sells:

- brand systems
- websites
- presentations
- content systems
- creative operations

Studio does not sell:

- payroll software
- accounting software
- governance tooling
- Faraday infrastructure

## Positioning

Primary statement:

From Idea to Production.

Secondary statement:

Websites, brands, content systems, presentations, campaigns, and digital experiences.
